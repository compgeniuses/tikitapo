🎯 CHOOSE YOUR METHOD:

═══════════════════════════════════════════════════════════════════════════════
 METHOD 1: Using Android Studio (RECOMMENDED - Most Reliable)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Build Web Assets
────────────────────────
Open Command Prompt in this folder and run:

    npm run build

✓ Should complete in ~10 seconds


STEP 2: Sync with Capacitor
───────────────────────────
Run:

    npx cap sync

✓ Should complete in ~5 seconds


STEP 3: Open Android Studio
───────────────────────────
Run:

    npx cap open android

This opens Android Studio.


STEP 4: Build Debug APK
───────────────────────
In Android Studio:

    1. Wait for Gradle sync to finish (first time: 5-10 minutes)
    2. Go to Build menu → Build Bundle(s) / APK(s) → Build APK(s)
    3. Wait for build to complete

✓ APK Location: android\app\build\outputs\apk\debug\app-debug.apk


STEP 5: Test on Your Phone
──────────────────────────
Option A - Via Android Studio:
    1. Connect Android phone via USB
    2. Enable USB Debugging on phone (Settings → Developer Options)
    3. Click green Run button (▶️) in Android Studio

Option B - Manual Install:
    1. Copy app-debug.apk to your phone
    2. Tap to install (enable "Unknown Sources" if prompted)

═══════════════════════════════════════════════════════════════════════════════
 METHOD 2: Using Command Line (Faster after initial setup)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Open Command Prompt in this folder

STEP 2: Run these commands one by one:

    npm run build
    npx cap sync
    cd android
    gradlew.bat assembleDebug

✓ First build may take 10-15 minutes (downloads dependencies)
✓ Subsequent builds are much faster (~1 minute)


STEP 3: Find your APK at:
    android\app\build\outputs\apk\debug\app-debug.apk

═══════════════════════════════════════════════════════════════════════════════
 BUILD RELEASE APK (For Distribution)
═══════════════════════════════════════════════════════════════════════════════

BEFORE building release, you MUST set up signing:

1. Create Keystore (one-time setup):

   cd android
   keytool -genkey -v -keystore release-key.keystore -alias tikitapo ^
     -keyalg RSA -keysize 2048 -validity 10000

2. Create android\key.properties file:

   storePassword=YOUR_PASSWORD
   keyPassword=YOUR_PASSWORD
   keyAlias=tikitapo
   storeFile=release-key.keystore

3. Build release APK:

   npm run build
   npx cap sync
   cd android
   gradlew.bat assembleRelease

✓ Location: android\app\build\outputs\apk\release\app-release.apk

⚠️  KEEP YOUR KEYSTORE SAFE! You need it for all future updates!

═══════════════════════════════════════════════════════════════════════════════
 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ "JAVA_HOME not set"
   → Download Java 17 from https://adoptium.net/

❌ "Gradle download timeout"
   → Use Android Studio method instead (more reliable)
   → OR check internet connection and try again

❌ "Build failed"
   → cd android
   → gradlew.bat clean
   → cd ..
   → npm run mobile:sync
   → Try build again

❌ "App crashes on phone"
   → Make sure you ran 'npm run build' before syncing
   → Try: npx cap sync
   → Clean build in Android Studio: Build → Clean Project
